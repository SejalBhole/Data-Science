# Power BI Practice: Skyscraper Heights

This repository contains my Power BI practice work done today. It is based on a training exercise from Wise Owl.

## About the Project
In this exercise, I analyzed a dataset of skyscrapers to compare building heights and counts across different countries and cities.

## What I Learned Today
By completing this exercise, I practiced and learned the following Power BI skills:
* **Card Visuals:** Created a card to show the total count of skyscrapers and formatted its title and labels.
* **Bar Charts:** Built a clustered bar chart to show the number of buildings in each country.
* **Conditional Formatting:** Used gradient colors (fx) on the chart bars so that countries with more skyscrapers automatically appear in a darker color.
* **Hierarchies & Drill-downs:** Added the "City" field under the "Country" field to create a data hierarchy. Learned how to turn on Drill Mode to click on a country and see the data for its cities.
* **Exploring Data:** Used the different arrow buttons (drill up, drill down, expand) to view the data at different levels
