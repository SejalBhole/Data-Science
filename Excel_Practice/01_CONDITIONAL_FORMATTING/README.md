# Excel Practice 01 --- Conditional Formatting

## Date

20 August 2026

## Topic

Conditional Formatting in Microsoft Excel

## What I Practiced

This was my first Excel practice focused on **Conditional Formatting**.
I practiced using formatting rules to make important values easier to
identify visually without changing the underlying data.

## Practical Exercises

I practiced applying conditional formatting to an accounting exam
results dataset, including:

-   Highlighting Candidate IDs where the value is below **300,000**
-   Highlighting candidates from **Southern regions**
-   Highlighting **Female** candidates
-   Highlighting candidates aged **40 or above**
-   Applying **Data Bars** to the Age column
-   Highlighting the **Top 5%** of exam results

## Skills Learned

-   Conditional Formatting
-   Highlight Cells Rules
-   Greater Than / Less Than conditions
-   Text-based conditional formatting
-   Percentage-based rules
-   Data Bars
-   Applying multiple conditional formatting rules to one dataset
-   Using formatting to quickly identify patterns and exceptions

## Key Learning

Conditional Formatting helps turn raw Excel data into something easier
to analyze. Instead of manually checking every row, Excel automatically
highlights values that meet a condition.

## Interview Takeaway

I can explain Conditional Formatting as:

> Conditional Formatting is an Excel feature that automatically changes
> the appearance of cells when they meet specified conditions. It is
> useful for quickly identifying trends, exceptions, high/low values,
> and important records in a dataset.
