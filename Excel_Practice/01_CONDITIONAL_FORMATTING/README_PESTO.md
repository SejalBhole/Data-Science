## Skills Learned

### Text-Based Rules

Used **Text Contains** to identify Staff IDs and surnames based on
specific text.

### Exact Match

Used **Equal To** to highlight a specific initial (`H`).

### Numeric Conditions

Used **Greater Than or Equal To** to highlight Hours Worked values of 18
or more.

### Top 10%

Used the **Top 10%** rule to identify the highest values in the Pay
column.

### Above Average

Used the **Above Average** rule to compare National Insurance values
against the average of the selected range.

### Data Bars

Used Data Bars in the Tax column to visually compare the size of
different values. Larger values display longer bars.

### Multiple Rules

Applied multiple Conditional Formatting rules to the Pension column to
create different visual results depending on whether values were above
or below the average.

### Icon Sets

Applied an Icon Set to Final Pay to visually categorize values using
arrows.

## Important Learning

Different Conditional Formatting tools are selected based on the
question being asked:

-   **Text Contains** → find cells containing specific text
-   **Equal To** → find an exact value
-   **Greater Than / Less Than / \>= / \<=** → apply numeric conditions
-   **Top/Bottom Rules** → identify the highest or lowest values
-   **Above Average** → compare values with the average
-   **Data Bars** → compare values visually
-   **Icon Sets** → show categories or performance levels
-   **Multiple Rules** → apply more than one condition to the same range

## Key Concept

Conditional Formatting is not only used to make a spreadsheet look
attractive. It is useful for **data analysis and reporting** because it
helps quickly identify patterns, exceptions, high/low values, and
important records.

## Interview Takeaway

> Conditional Formatting is an Excel feature that automatically changes
> the formatting of cells when they meet specified conditions. I can use
> different rules such as text conditions, numeric thresholds, Top 10%,
> Above Average, Data Bars, and Icon Sets depending on the analysis
> requirement.

## Practical Learning

I also learned that **Icon Sets depend on their threshold settings**.
The arrows are assigned according to the Conditional Formatting rule, so
changing the rule type or thresholds can change which values receive
different icons.
